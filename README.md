# Pinecone - An RP2040 powered dev board
#### What is it?
Pinecone is an RP2040 powered dev board, inspired by the legendary Arduino Uno line-up. It features things like a USB-C port which the Unos simply lack.
#### Why?
I created this to jump-start and expand my hobby in electronics by designing and hopefully manufacturing my first PCB. I also previously used the Uno R3, and thought there are alot of things i could do to improve it, while making it smaller.

### Here are some cool features Pinecone has
- RP2040
- 16MB of fast, QSPI Flash
- USB-C
- 29 GPIOs broken out into easy to use sockets
- Neopixel
- Power-On LED
- ESD and Voltage spike protection
- Small, 5cm x 5cm pcb size
